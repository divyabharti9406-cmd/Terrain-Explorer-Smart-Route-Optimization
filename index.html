01. Problem Statement

Travelling across uneven terrain can be difficult because some routes have steep slopes. Selecting a suitable route requires understanding elevation changes and comparing possible paths.

Why is this problem important?

  • Steep paths can require more effort.
  • Elevation changes affect route suitability.
  • Manual route selection may overlook easier alternatives.
  • Mathematical analysis can support better route decisions.

Project Objectives

  1. Build a mathematical terrain model.
  2. Calculate partial derivatives.
  3. Measure terrain steepness using the gradient.
  4. Visualise elevation and slope variation.
  5. Compare and optimise possible routes.

02. Mathematical Model

We represent the terrain as a function of two horizontal coordinates. The height at each location is calculated using the following equation.

Terrain Function

z = f(x,y) = 0.08(x² + y²) + 4e-((x-2)²+(y-1)²)/5

Variables

  • x: Horizontal coordinate.
  • y: Vertical coordinate on the map.
  • z: Terrain elevation.
  • f(x,y): Height at a particular location.

Model Assumptions

  • Terrain is continuous and differentiable.
  • Elevation is represented by a simulated equation.
  • Route movement is represented by a grid.
  • Slope is used as a simplified measure of route difficulty.

Important: This is a simulated mathematical terrain, not real-world GIS or satellite elevation data.

03. Calculus Concepts Used

The project connects calculus concepts with the mathematical calculations performed in Python.

Partial Derivatives

They measure how elevation changes when one coordinate changes while the other remains fixed.

∂f/∂x and ∂f/∂y

Python: sp.diff(f, x) and sp.diff(f, y)

Gradient

The gradient combines both partial derivatives and indicates the direction of the steepest increase.

∇f = (fx, fy)

Python: Calculate both derivatives and evaluate them at a point.

Slope Magnitude

The magnitude of the gradient measures how quickly elevation changes across the terrain.

|∇f| = √(fx² + fy²)

Python: np.sqrt(fx**2 + fy**2)

Slope Angle

Converts the gradient magnitude into an angle in degrees.

θ = tan⁻¹(|∇f|)

Python: np.degrees(np.arctan(slope))

Taylor Series and Linearization

Approximates the terrain height near a known point using a local linear model.

f(x,y) ≈ f(a,b) + fx(a,b)(x-a) + fy(a,b)(y-b)

Application: Estimate small elevation changes near a point.

Optimization

Compares possible routes using distance and slope-related cost.

Route Cost = Σ [distance × (1 + λ × slope)]

Python: Dijkstra's algorithm searches for a minimum-cost path.

Concepts not implemented in this model

Backpropagation is mainly used to train neural networks. Since this project uses a mathematical terrain function and graph-based route optimisation rather than a neural network, backpropagation is not required in the current implementation.

Gradient descent is another optimisation method, but the current route search uses Dijkstra's algorithm. Do not claim that gradient descent or backpropagation is implemented in this project.

08. Pseudocode and Algorithm

General steps followed by the route optimisation process.

Pseudocode

START

Define terrain function f(x, y)

Calculate partial derivatives:
    fx = ∂f/∂x
    fy = ∂f/∂y

Create a grid of terrain coordinates

For every grid point:
    Calculate elevation
    Calculate gradient magnitude
    Calculate slope angle

Set starting point and destination

Run Dijkstra with distance-based edge cost
Store shortest-distance route

Run Dijkstra with slope-aware edge cost
Store optimised route

Display:
    3D terrain
    Slope heatmap
    Route comparison
    Calculated results

END

Algorithm Explanation

  1. Generate terrain coordinates.
  2. Calculate elevation at every grid point.
  3. Calculate partial derivatives and local slope.
  4. Represent neighbouring grid points as connected nodes.
  5. Assign a cost to each movement.
  6. Use Dijkstra's algorithm to find a minimum-cost route.
  7. Compare the two routes and display the result.

09. Python Implementation

The following is a Python reference implementation of the mathematical model and terrain analysis. It uses SymPy, NumPy, Pandas and Matplotlib.

Python Code

import sympy as sp
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Define symbolic variables
x, y = sp.symbols('x y')

# Define terrain function
f = (
    0.08 * (x**2 + y**2)
    + 4 * sp.exp(-((x-2)**2 + (y-1)**2)/5)
)

# Calculate partial derivatives using SymPy
fx = sp.diff(f, x)
fy = sp.diff(f, y)

print("Terrain function:", f)
print("Partial derivative fx:", fx)
print("Partial derivative fy:", fy)

# Convert symbolic functions into numerical functions
height = sp.lambdify((x, y), f, 'numpy')
dx = sp.lambdify((x, y), fx, 'numpy')
dy = sp.lambdify((x, y), fy, 'numpy')

# Create coordinate grid
X = np.linspace(-10, 10, 60)
Y = np.linspace(-10, 10, 60)
X, Y = np.meshgrid(X, Y)

# Calculate elevation
Z = height(X, Y)

# Calculate gradient
FX = dx(X, Y)
FY = dy(X, Y)

# Calculate slope magnitude and angle
slope = np.sqrt(FX**2 + FY**2)
angle = np.degrees(np.arctan(slope))

# Store sample results using Pandas
results = pd.DataFrame({
    'X': X.ravel(),
    'Y': Y.ravel(),
    'Elevation': Z.ravel(),
    'Slope': slope.ravel(),
    'Slope Angle': angle.ravel()
})

print(results.head())

# Plot 3D terrain
fig = plt.figure(figsize=(10, 7))
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, cmap='terrain')
ax.set_title('Simulated Terrain Model')
ax.set_xlabel('X coordinate')
ax.set_ylabel('Y coordinate')
ax.set_zlabel('Elevation')
plt.show()

# Plot slope heatmap
plt.figure(figsize=(8, 6))
plt.contourf(X, Y, angle, levels=20, cmap='RdYlGn_r')
plt.colorbar(label='Slope angle (degrees)')
plt.title('Terrain Slope Heatmap')
plt.xlabel('X coordinate')
plt.ylabel('Y coordinate')
plt.show()

This Python code performs mathematical terrain analysis and visualisation. The interactive website separately performs its calculations in JavaScript; it does not execute this Python code or connect to a Python backend.

12. Challenges, Limitations and Future Scope

Challenges

  • Understanding partial derivatives and gradients.
  • Converting mathematical expressions into code.
  • Representing terrain as a grid.
  • Comparing distance and slope-based route costs.

Current Limitations

  • Terrain is simulated, not based on measured elevation.
  • Route search uses a finite grid.
  • Only slope and distance are considered in route cost.
  • Obstacles and real-world travel conditions are not included.

Future Scope

  • Use real elevation data from GIS or digital elevation models.
  • Add obstacles and restricted areas.
  • Include travel time and energy consumption.
  • Explore A* route search and more advanced optimisation.
  • Connect the model to real terrain mapping systems.

Real-world Applications

  • Hiking and trekking route planning.
  • Road and infrastructure planning.
  • Agricultural vehicle movement.
  • Terrain navigation and robotics.
