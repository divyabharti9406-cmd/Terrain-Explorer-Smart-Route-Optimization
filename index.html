01. Mathematical Model

We represent uneven terrain using a function of two variables:

z = f(x,y) = 0.08(x² + y²) + 4e-((x-2)²+(y-1)²)/5

Variables

x: Horizontal coordinate

y: Vertical coordinate

z: Elevation or height

Purpose

Calculate elevation at different locations, understand terrain steepness and compare possible routes.

This is a simulated terrain model, not real-world elevation data.

02. Calculus Concepts

1. Partial Derivatives

Measure the change in elevation with respect to one variable while keeping the other variable constant.

fx = ∂f/∂x
fy = ∂f/∂y

Python: sp.diff(f,x), sp.diff(f,y)

2. Gradient

Combines the two partial derivatives and indicates the direction of the steepest increase in elevation.

∇f = (fx, fy)

Python: Evaluate both partial derivatives at a point.

3. Gradient Magnitude

Measures how quickly the terrain elevation changes.

|∇f| = √(fx² + fy²)

Python: np.sqrt(fx**2 + fy**2)

4. Slope Angle

Converts the gradient magnitude into an angle in degrees.

θ = tan⁻¹(|∇f|)

Python: np.degrees(np.arctan(slope))

5. Taylor Series & Linearization

Approximates elevation near a known point using a first-order linear equation.

f(x,y) ≈ f(a,b) + fx(a,b)(x-a) + fy(a,b)(y-b)

Application: Estimate nearby elevation changes.

6. Optimization

Compares possible routes using distance and slope-related cost.

Cost = Σ [distance × (1 + λ × slope)]

Algorithm: Dijkstra's shortest-path algorithm.
