Mathematical Analysis

1. Terrain Function
z = f(x,y)
Represents the elevation of the land using two coordinates.
2. Partial Derivative
∂z / ∂x, ∂z / ∂y
Measures the change in elevation along each coordinate direction.
3. Gradient
∇f = (fx, fy)
Indicates the direction of maximum elevation increase.
4. Gradient Magnitude
|∇f| = √(fx² + fy²)
Measures the maximum rate of terrain height change.
5. Slope Angle
θ = tan⁻¹(|∇f|)
Converts gradient magnitude into an angle in degrees.
6. Hessian Matrix
H = [fxx fxy; fyx fyy]
Contains second-order derivatives for curvature analysis.

Project Methodology

01. Terrain modelling: Create a two-variable mathematical elevation function.

02. Derivative calculation: Calculate partial derivatives and gradients.

03. Slope analysis: Measure terrain steepness and visualize it using a heatmap.

04. Graph construction: Represent terrain locations as connected nodes.

05. Route optimization: Apply Dijkstra's algorithm to find a minimum-cost route.

06. Visualization: Display the terrain and compare the selected routes.
